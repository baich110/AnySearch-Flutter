# AnySearch-Flutter

AnySearch 跨平台版 - Flutter (Android + Windows + Web)

基于 AnySearch MCP 后端的多源聚合搜索引擎 + 无广告阅读器。

## 功能

- 多源聚合搜索（单行/多行/垂直三种模式）
- 网页正文提取 + Markdown 渲染
- 内置腾讯翻译（分块翻译）
- 搜索历史
- 软件更新检查
- 全平台无障碍支持（TalkBack / NVDA / VoiceOver）

## 构建

GitHub Actions 自动构建 Android APK、Windows EXE 和 Web。

## 技术

- Flutter 3.32+
- Dart 3.32+
- dio (网络)
- flutter_markdown (渲染)
- provider (状态管理)
- window_manager (桌面窗口)
